## 데이터 처리

`analysis.py`의 `정제(df)` 함수는 원본 데이터프레임을 복사한 뒤 다음 순서로 처리합니다.

1. 점수가 비어 있는 행을 제거합니다.
2. 모든 열의 값이 같은 중복 행을 제거합니다.
3. `반`과 `과목` 값의 앞뒤 공백을 제거합니다.
4. 점수가 0~100 범위를 벗어난 행을 제거합니다.

기본 데이터인 `scores_2026.csv`는 114행으로 시작하며, 정제 후 100행이 남습니다. `반별평균(df)`는 반별 점수의 개수·평균·중앙값·최댓값을 출력하고 평균을 반환합니다. 스크립트를 직접 실행하면 과목 및 반별 필터링·평균 집계 결과도 출력합니다.

## 파일 구성

- `analysis.py` — 정제 및 반별 통계 함수, 분석 실행 코드
- `test_analysis.py` — 데이터 정제와 집계 결과를 확인하는 pytest 테스트
- `scores_2026.csv` — 기본 분석 데이터(UTF-8)
- `scores_2026_cp949.csv` — 같은 형식의 CP949 인코딩 데이터
- `mini.csv` — 간단한 정제·평균 확인용 데이터
- `prompts.txt` — 12주차 실습 프롬프트 원문

CP949 파일을 읽을 때는 인코딩을 지정해야 합니다.

```python
pd.read_csv("scores_2026_cp949.csv", encoding="cp949")
```

## 실행 방법

프로젝트 폴더에서 PowerShell 기준으로 실행합니다.

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install pandas pytest
python -m pytest -q
python analysis.py
```

`analysis.py`와 테스트는 CSV 파일을 상대 경로로 읽으므로 프로젝트 폴더에서 실행해야 합니다.
