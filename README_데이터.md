# 2026년 점수 데이터 명세

## 출처

수업에서 배포한 실습 자료 `scores_2026.csv`를 사용합니다. 파일은 UTF-8 인코딩이며, 같은 데이터의 CP949 인코딩 버전도 `scores_2026_cp949.csv`로 제공됩니다.

## 행 수와 열 설명

`scores_2026.csv`에는 헤더를 제외하고 **114행, 5열**이 있습니다. 데이터 정제 후에는 **100행**이 남습니다.

| 열 | 뜻 | 자료형 |
|---|---|---|
| 학번 | 학생 번호 | 문자 |
| 이름 | 학생 이름 | 문자 |
| 반 | 학생이 속한 반 (1반 또는 2반) | 문자 |
| 과목 | 수강 과목 (프로그래밍, 영어, 수학) | 문자 |
| 점수 | 과목 점수 (0~100) | 정수 |

## 빈 점수 처리와 이유

점수가 비어 있는 행 **6개**를 제거합니다(114행에서 108행으로 감소). 평균이나 0점으로 채우면 실제로 받지 않은 점수가 반 평균에 섞여 결과가 왜곡되기 때문입니다.

## 정제 기준

`analysis.py`에서는 다음 기준으로 데이터를 정제합니다.

1. 점수가 비어 있는 행을 제거합니다.
2. 모든 열의 값이 완전히 같은 중복 행은 하나만 남깁니다.
3. 반과 과목 값의 앞뒤 공백을 제거합니다.
4. 점수가 0~100 범위를 벗어난 행을 제거합니다.

위 기준을 적용하면 114행에서 100행이 남습니다.
